# Microsoft 365 imports

The export contains **15 selected app/planning/review/handoff skills** and four
configuration recipes, including Enterprise App Builder for Microsoft 365
Copilot for work and Work IQ. Enabled M365/Work IQ operations use their actual
tools and policies; code, deployment and local recovery use the supported
developer or maker host. A skill does not create a shell, browser, connector or
tenant permission. The profile JSON is a recipe to configure an agent, not a Microsoft
app manifest or one-click deployment package.

Generate from the toolkit:

```powershell
npm run export:m365
```

Open `dist/m365/packages.json` for filenames, sizes and SHA-256 hashes. Each ZIP
has SKILL.md at the root and only that skill's own resources. Repeated export
produces identical package bytes for unchanged content.

## Agent Builder

Choose a recipe in profiles/: Enterprise App Builder, App Planner, App Assurance
or Agent Designer. Enterprise App Builder attaches ms-app, Work IQ, enterprise
controls and native UX within the eight-skill limit.
Read its JSON for skill names, name/description, starter prompts and instructions.
Paste the corresponding instructions.txt into the agent's Instructions field.
Configure only the knowledge/connectors actually needed and authorized.

In Agent Builder, open/create the intended agent, go to Configure → Skills → Add,
upload each named complete ZIP, inspect the imported files and test on Try it.
The current documented agent limits are up to eight skills, under 20,000
instruction characters per skill, 50 MB per ZIP, 25 MB per file, 350 files across
the agent's skills and directory depth three. This exporter validates the selected
profiles against those limits conservatively, including the entire SKILL.md in
the character check. Each recipe contains at most eight skills.
[Upload guide](https://learn.microsoft.com/en-us/plugins/agent-builder-add-skills) ·
[Support matrix](https://learn.microsoft.com/en-us/plugins/declarative-agent-skills)

Subscription, tenant controls, Information Barriers, tool availability and rollout
still apply. Upload success does not prove invocation or access. Use a harmless
representative request and inspect actual tool/results before publishing/sharing.

## Personal Microsoft 365 Copilot Chat

Microsoft separately documents direct Chat skill uploads: a standalone SKILL.md
or a ZIP with SKILL.md at its root. Follow the current Chat UI's Upload skill
route and verify discovery plus a small actual request. Do not apply the Agent
Builder limit of eight skills as a claim about personal Chat limits.
[Personal Chat guidance](https://learn.microsoft.com/en-us/plugins/build-copilot-chat-skills)

## Copilot Studio and pro-code paths

Copilot Studio's skill import is harness-specific. Check that the actual agent
exposes Skills and confirm its current format/UI. The documented route accepts
a Markdown file or ZIP in supported agents; it is separate from repository skill
installation. Test the published channel and intended identity separately from
the maker's preview. [Studio upload](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/skills-add-existing)

The Agent Builder ZIP is not an Agents Toolkit directory import or complete app
package. Current Toolkit limits differ, including the overall app package size.
The documentation also points new supported pro-code scenarios toward Work IQ
Dev Tools with feature-specific prerequisites. Check those current references
with ms-refresh before choosing that route. This toolkit does not invent a schema
or submit any app to an organization/store.
