description: "Prepare a verified app release, deployment destination, smoke checks and rollback."
---

Use ms-ship. Check current working content, quality targets and evidence rather
than relying on a historic green result. Finish local preparation and a concrete
release package. Execute only the PR/deployment/publication actions authorized by
the user. Confirm actual results and readiness gaps. Do not treat a prepared ZIP,
passing build or uploaded package as a verified live installation.
